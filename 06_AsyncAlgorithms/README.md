# 06_AsyncAlgorithms

10 async/await recipes that mirror the Combine set, using `AsyncSequence`, `AsyncStream`, and the `swift-async-algorithms` package.

## Recipes

1. Observable
2. Computed
3. Debounce
4. CombineLatest
5. Filter
6. AsyncStream
7. Merge
8. Chaining
9. Timer
10. Networking

## Getting Started

This lab uses Tuist. To open it:

```bash
cd AsyncRecipes
tuist generate
open AsyncRecipes.xcodeproj
```
