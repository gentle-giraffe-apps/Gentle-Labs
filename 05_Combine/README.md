# 05_Combine

10 standalone Combine recipes, each in its own file with matching unit tests. Plus an interactive playground for experimenting with operator ordering.

## Recipes

1. BasicPublished
2. Map
3. Debounce
4. CombineLatest
5. Filter
6. Subjects
7. Merge
8. FlatMap
9. Timer
10. Networking

## Contents

| Path | Description |
|------|-------------|
| `CombineRecipes/` | Recipe app with 10 recipes and unit tests |
| `CombineOperatorOrdering.playground/` | Interactive playground for operator ordering |

## Getting Started

This lab uses Tuist. To open it:

```bash
cd CombineRecipes
tuist generate
open CombineRecipes.xcodeproj
```
